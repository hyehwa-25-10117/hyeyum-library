# 혜윰도서관

혜화여자고등학교 도서관 웹사이트 만들기 수업 프로젝트입니다.

## 기능1 · 혜윰도서관 사이트

`기능1/index.html` 한 파일로 된 웹사이트입니다. 내려받아 브라우저로 열면 바로 작동합니다.

- 홈: 공지사항, 이달의 추천 도서, 날짜별 이용 시간, 나의 대출 요약
- 자료 검색: 검색 결과 → 책 상세, 없는 책은 혜화여고 도서관(독서로)에서 찾기
- 대출현황: 연장 신청 → 연장 완료, 연체된 책이 있으면 연장 불가
- 이용 시간: 휴관일이면 휴관 배지 표시
- 추천 도서: 벌집 모양 추천과 책 상세
- 책 위치: 서가 지도와 입구부터 길 안내
- 공지사항: 행사·휴관 일정으로 자동 생성
- 챗봇 윰이

디자인은 서가 디자인 시스템(도쿄대 도서관 구조 + 유니버설 스튜디오 재팬 스타일)을 따릅니다.
도서·대출·일정·운영 시간은 모두 수업용 예시이며, 책 표지 이미지는 알라딘에서 가져왔습니다.
